Awesome Learn is an open-source project that provides structured, curated learning paths across technology, digital skills, science, professional development, and more.

---

🛠️ **Status:** Actively Maintained  
🎯 **Focus:** AI, programming, decentralized systems, sustainability, digital skills, travel, and modern web ecosystems.  

> **Part of the Awesome Ecosystem:**  
> • **Awesome Learn** — learn topics step-by-step with clarity and guidance  
> • **[Awesome Lists](https://github.com/brandonhimpfen/awesome-lists)** — discover the best tools & resources  
> • **[Awesome Travel](https://github.com/brandonhimpfen/awesome-travel)** — curated tools, guides & data for travelers and digital nomads  

Together, these projects form the **Awesome Learning Ecosystem**: a unified way to explore, learn, and apply knowledge.

---

## 📚 Learn Anything — One Topic at a Time  

Below is the evolving index of learning paths maintained across the Awesome Learn ecosystem.

Each topic includes **beginner → advanced** steps, curated resources, essential books, documentation, exercises, and next steps.

- [Programming & Computer Science](#programming--computer-science)

### Programming & Computer Science

Foundational and advanced guides for developers learning languages, algorithms, and core CS concepts.

- **[Awesome Learn Python](https://github.com/brandonhimpfen/awesome-learn-python)** – A beginner-friendly and highly versatile language.  
- **[Awesome Learn Go](https://github.com/brandonhimpfen/awesome-learn-go)** – A modern, efficient language for cloud and systems development.  
- **Awesome Learn Rust** – Safe, fast, and ideal for systems programming.  
- **Awesome Learn JavaScript** – The language of the web.  
- **[Awesome Learn Databases](https://github.com/brandonhimpfen/awesome-learn-databases)** – Foundations of storing and querying data.  
- **Awesome Learn Algorithms & Data Structures** – CS fundamentals for interviews and real-world problem solving.  
- **Awesome Learn Computer Science Foundations** – Core CS concepts for all developers.  

### Web Development

Learn the building blocks of the modern web, from frontend to backend.

- **Awesome Learn HTML & CSS** – The essentials of web structure and design.  
- **Awesome Learn Frontend Development** – Frameworks, tooling, and modern browser apps.  
- **Awesome Learn Backend Development** – APIs, servers, architecture, and production best practices.  
- **Awesome Learn Web Security** – Protecting applications and users.  
- **Awesome Learn DevOps Basics** – CI/CD, environments, servers, and deployment.  

### Artificial Intelligence & Data

Guides to modern AI, machine learning, LLMs, and practical data analysis.

- **Awesome Learn Machine Learning** – Core ML concepts and model building.  
- **Awesome Learn Deep Learning** – Neural networks, vision models, transformers.  
- **Awesome Learn Large Language Models** – LLM fundamentals and applied use-cases.  
- **[Awesome Learn Prompt Engineering](https://github.com/brandonhimpfen/awesome-learn-prompt-engineering)** – Writing effective prompts for AI systems.
- **[Awesome Learn AI Workflows](https://github.com/brandonhimpfen/awesome-learn-ai-workflows)** – Understanding, designing, and improving AI-assisted workflows.
- **Awesome Learn MLOps** – Deploying, monitoring, and managing ML systems.  
- **Awesome Learn Data Analysis** – Extract insights from structured and unstructured data.  

### Digital Skills

Modern digital competencies for creators, marketers, analysts, and online professionals.

- **Awesome Learn SEO** – Ranking content and understanding search systems.  
- **Awesome Learn Digital Marketing** – Channels, analytics, funnels, audience growth.  
- **Awesome Learn Analytics** – Measure performance and make data-driven decisions.  
- **Awesome Learn Content Creation** – Writing, publishing, media strategy.  
- **Awesome Learn UX Writing** – Microcopy, clarity, and user-centered communication.  
- **Awesome Learn Automation** – Tools and workflows to optimize digital work.  

### Professional & Practical Skills 

Career, communication, finance, and productivity skills that compound over time.

- **Awesome Learn Personal Finance** – Money management, savings, and long-term planning.  
- **Awesome Learn Communication** – Effective writing, speaking, and clarity.  
- **Awesome Learn Productivity** – Systems, habits, and tools to work better.  
- **Awesome Learn Career Development** – Job searching, interviewing, growth strategy.  

### Travel & Global Learning

Skills for solo travelers, digital nomads, and globally minded learners.

- **Awesome Learn Solo Travel Skills** – Safety, planning, mindset, and confidence.  
- **Awesome Learn Digital Nomadism** – Remote work, logistics, visas, and sustainability.  
- **Awesome Learn Cultural Etiquette** – Navigating customs and communication around the world.  
- **Awesome Learn Essential Travel Safety** – Managing risk and staying prepared.
- **Awesome Learn Global English Variants** – Understanding international English usage.
